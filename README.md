# JavaScript API Product Explorer

A small personal project built to practice JavaScript, REST APIs, asynchronous requests, DOM manipulation, filtering, and responsive UI.

## Features

- Fetches product data from a REST API
- Displays products dynamically
- Search by product name
- Filter by category
- Handles API errors
- Responsive layout for desktop and mobile

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- REST API
- DOM manipulation

## API

This project uses the public DummyJSON Products API:

https://dummyjson.com/products

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Make sure you have an internet connection so the product data can be loaded from the API.

## Personal Project

This project was created to practice and demonstrate JavaScript, API integration, data handling, filtering, and front-end development skills.
